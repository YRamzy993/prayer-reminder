# مذّكر الصلاة

[English](README.md) · **العربية**

تطبيق صغير لويندوز يقعد في منطقة الإشعارات (جنب الساعة)، وينبّهك قبل كل صلاة بمواقيت محسوبة
للمكان اللي جهازك فيه فعلًا.

بلا حساب، وبلا إعلانات، وبلا أي تتبّع. يُحمّل مواقيت شهر كامل دفعة واحدة، فيستمر في تنبيهك
حتى لو انقطع الإنترنت.

## التحميل

[<img src="https://get.microsoft.com/images/en-us%20dark.svg" height="48" alt="احصل عليه من متجر مايكروسوفت">](https://apps.microsoft.com/detail/9N0PNDJPZ6ZX)

أو من سطر الأوامر:

```powershell
winget install --id 9N0PNDJPZ6ZX --source msstore
```

نسخة المتجر موقّعة من مايكروسوفت، فلا تظهر معها أي شاشة تحذير، وتُحدِّث نفسها تلقائيًا. وهي
الطريقة المفضّلة للتثبيت.

<details>
<summary>تفضّل مثبّتًا عاديًا، أو ليس لديك حساب على المتجر؟</summary>

**[⬇ حمّل المثبّت](../../releases/latest)** — الملف `PrayerReminder-Setup-x.y.z.exe`

التثبيت للمستخدم الحالي فقط، فلا يطلب ويندوز صلاحيات المسؤول.

> سيُظهر ويندوز شاشة زرقاء مكتوب عليها "Windows protected your PC"، لأن هذا المثبّت غير
> موقّع رقميًا (شهادة التوقيع تكلّف مئات الدولارات سنويًا). اضغط **More info ← Run anyway**،
> أو ابنِ التطبيق بنفسك من المصدر بالخطوات في الأسفل. نسخة المتجر لا تواجه هذه المشكلة.

</details>

في الحالتين ينتهي الأمر بمجرد تشغيله: يظهر في منطقة الإشعارات، ويبدأ مع ويندوز.

## ماذا يفعل

- 🕌 تنبيه قبل كل صلاة (١٥ دقيقة افتراضيًا) وتنبيه آخر عند دخول الوقت تمامًا
- 🌍 واجهة **عربية** كاملة من اليمين إلى اليسار، تتبع لغة ويندوز تلقائيًا
- 🔊 يشغّل تكبيرًا قصيرًا، أو صوتًا من أصوات ويندوز، أو أي ملف صوتي تختاره
- 🗣️ ينطق التذكير بصوت مسموع، بالعربية عند تثبيت صوت عربي في ويندوز
- 📍 يحدّد موقعك تلقائيًا، ويتابع الجهاز أثناء السفر
- 💤 تأجيل أو إغلاق، مع إغلاق تلقائي اختياري
- 📴 يعمل بدون إنترنت من مواقيت شهر محفوظة على جهازك
- ⏸️ إيقاف التنبيهات مؤقتًا متى شئت

اضغط على الأيقونة في منطقة الإشعارات لترى مواقيت اليوم، و**الإعدادات**، و**تجربة التنبيه**،
و**إيقاف التنبيهات مؤقتًا**، و**إنهاء**. ومرّر الفأرة فوقها لترى الصلاة القادمة والوقت المتبقي لها.

## الإعدادات

كلها في نافذة واحدة: اضغط على الأيقونة ← **الإعدادات…**

| الإعداد | ملاحظات |
|---|---|
| الموقع | تلقائي (يتابع الجهاز) أو إدخال خط الطول والعرض يدويًا |
| طريقة الحساب | ٢٣ طريقة — رابطة العالم الإسلامي، والهيئة المصرية العامة للمساحة، وأم القرى، وكراتشي، وديانت، وغيرها |
| حساب العصر | مذهب الجمهور (الشافعي والمالكي والحنبلي) أو المذهب الحنفي |
| الصلوات | أيّها ينبّهك، مع تعديل ±٣٠ دقيقة لكل صلاة لمطابقة مسجدك |
| التنبيه قبل | عدد الدقائق قبل الصلاة، أو ٠ لإيقاف التنبيه المبكر |
| عند دخول الوقت | تنبيه ثانٍ في الوقت تمامًا |
| التأجيل والإغلاق التلقائي | مدة التأجيل، وهل تُغلق النافذة نفسها |
| صوت التنبيه | التكبير المرفق، أو أي صوت من ويندوز، أو ملف mp3/wav خاص بك — مع زر **تشغيل** للتجربة |
| الأذان عند دخول الوقت | ملف أذان كامل اختياري، يُستخدم فقط مع تنبيه دخول الوقت |
| النطق بصوت مسموع | يقول أي صلاة هي، بالعربية إن توفّر صوت عربي |
| البدء مع ويندوز | مُفعّل افتراضيًا |
| اللغة | تلقائي (حسب ويندوز)، أو العربية، أو English |

### الصوت العربي

النطق يكون بالإنجليزية حتى تضيف صوتًا عربيًا إلى ويندوز:
**الإعدادات ← الوقت واللغة ← الكلام ← إضافة أصوات ← العربية**. بعدها يقول
*«باقي ١٥ دقيقة على صلاة العصر»* بدلًا من الجملة الإنجليزية.

### أذان بصوت من تفضّل

يأتي التطبيق بتكبير قصير في الملك العام. ولاستخدام صوت قارئ بعينه، ضع الملف في أي مكان على
جهازك واخترْه من الإعدادات — في خانة **صوت التنبيه** إن كان مقطعًا قصيرًا، أو في خانة
**الأذان** للأذان الكامل عند دخول الوقت.

> يُرجى استخدام نسخة يحقّ لك استخدامها. لا يأتي التطبيق بأي تسجيل أذان.

## أين تُحفظ إعداداتك

```
%APPDATA%\PrayerReminder\config.json   الإعدادات
%APPDATA%\PrayerReminder\cache\        المواقيت المحفوظة والمقاطع المنطوقة
%APPDATA%\PrayerReminder\prayer-reminder.log
```

إزالة التطبيق تُبقي ملف `config.json` في مكانه، فتعود إعداداتك عند إعادة التثبيت. احذف المجلد
كله إن أردت البدء من جديد.

## المواقيت

المواقيت من [واجهة Aladhan](https://aladhan.com/prayer-times-api)، وتعتمد على الحساب الفلكي
المعروف. **قارن مواقيت أول يوم بمسجدك** — فإن اختلفت، عدّل طريقة الحساب، أو مذهب العصر، أو
دقائق التعديل لكل صلاة حتى تتطابق. والاختلاف اليسير بين المساجد أمر معتاد.

## التشغيل من المصدر

لا يحتاج إلى بناء، فـ PowerShell 5.1 يأتي مع ويندوز ١٠ و١١:

```powershell
git clone https://github.com/YRamzy993/prayer-reminder
cd prayer-reminder
wscript src\PrayerReminder.vbs
```

## بناؤه بنفسك

```powershell
Install-Module ps2exe -Scope CurrentUser
winget install JRSoftware.InnoSetup

.\build\build.ps1 -Version 1.0.0        # dist\PrayerReminder.exe مع المثبّت
.\build\build-msix.ps1                  # dist\*.msix غير موقّع، ليوقّعه المتجر
.\build\build-msix.ps1 -SelfSign        # نفسه موقّعًا ذاتيًا، للتجربة محليًا
.\build\make-screenshots.ps1            # لقطات المتجر، من الواجهة الحقيقية
.\build\make-screenshots.ps1 -Lang ar   # نفسها بالعربية من اليمين إلى اليسار
```

يُنزّل `build-msix.ps1` أدوات بناء Windows SDK (نحو ٢٢ ميجابايت) من nuget.org عند أول تشغيل،
بدلًا من طلب حزمة SDK كاملة. تفاصيل النشر على المتجر في
[store/SUBMISSION.md](store/SUBMISSION.md).
